Configuración de API

Instrucciones para obtener tu clave

  1. Accede a Google AI Studio e inicia sesión con tu cuenta de Google.
  2. Haz clic en el botón Create API key.
  3. Selecciona un proyecto existente o crea uno nuevo y confirma.
  4. Copia la clave generada y pégala en el campo superior.

Privacidad: La clave se almacena exclusivamente en tu navegador (localStorage) y se comunica de forma directa con la API de Google sin intermediarios.
