Instrucciones para obtener tu clave

  1. Accede a Google AI Studio e inicia sesión con tu cuenta de Google.
  2. Haz clic en el botón Create API key.
  3. Selecciona un proyecto existente o crea uno nuevo y confirma.
  4. Copia la clave generada y pégala en la configuración de API de Nexo-Bot.

Privacidad: La clave se almacena exclusivamente en tu navegador (localStorage) y se comunica directamente con la API de Google.

¿Cómo utilizar Nexo-Bot?

  1. Configura tu API Key desde el botón Clave.
  2. Selecciona el modelo de Gemini disponible.
  3. Escribe tu pregunta en el área de conversación.
  4. Pulsa Enviar o utiliza la tecla Enter.
